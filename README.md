### What's the point?

This repo is a collection of quick notes on how to crack machines. The logic is simple:

*   **No Time Wasted:** Don't wait for someone to say "uhh" or "umm" in a video. Get the command you need in seconds.
*   **Your Own Logic:** In a video, you just follow a cursor. Here, you read the path and execute it yourself, so you actually understand the logic.
*   **Pure Info:** No fluff, no useless talk. Just the commands that work and the path taken.

---

### What's inside?

Each writeup follows a straightforward flow:
1.  **Scanning:** Where are the doors?
2.  **Discovery:** What’s hidden?
3.  **Exploitation:** How to get in?
4.  **Root:** Full control of the machine.
